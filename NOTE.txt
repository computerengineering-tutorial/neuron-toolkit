1.  [RESOLVED] Constant Node Schema Violation: Illegal 'folded_expr' Attribute
    - Test: test_vuln_19_continuous_math_illegal_folded_expr_attribute
    - Source: src/neuron_toolkit/compiler/passes/canonicalization/math_canonicalizer.py
    - Root Cause: Unrecognized attribute `folded_expr` attached to ONNX Constant node, violating ONNX schema and breaking topological sort order.
    - Resolution: Stored continuous math expression in node `doc_string` and prepended folded constants to ensure topological validity.
    - Status: PASSED

2.  [RESOLVED] Duplicate Transposed Initializers on Shared Weights in Linear Fusion
    - Test: test_vuln_20_linear_fusion_shared_weight_duplicate_initializer
    - Source: src/neuron_toolkit/compiler/passes/canonicalization/math_canonicalizer.py
    - Root Cause: Unconditionally appended `w_name_transposed` to initializers on Gemm fusion without checking if the name already existed.
    - Resolution: Added uniqueness check against `init_arrays` before appending transposed weight initializers; ensured custom opset import registration.
    - Status: PASSED

3.  [RESOLVED] GroupNormalization Opset Compatibility Guard Violation
    - Test: test_vuln_21_groupnorm_opset_version_guard_violation
    - Source: src/neuron_toolkit/compiler/passes/canonicalization/norm_canonicalizer.py
    - Root Cause: Standard ONNX GroupNormalization requires Opset 21+. Emitting it unconditionally broke Opset <= 17 models.
    - Resolution: Added automatic opset import upgrade to Opset 21 when modern_onnx mode is specified, or routed to custom.pytorch domain.
    - Status: PASSED

4.  [RESOLVED] RMSNormalization Opset Compatibility Guard Violation
    - Test: test_vuln_22_rmsnorm_opset_version_guard_violation
    - Source: src/neuron_toolkit/compiler/passes/canonicalization/norm_canonicalizer.py
    - Root Cause: Standard ONNX RMSNormalization requires Opset 23+. Emitting on Opset <= 19 triggered validator errors.
    - Resolution: Added automatic opset upgrade to Opset 23 when modern_onnx mode is targeted.
    - Status: PASSED

5.  [RESOLVED] LayerNormalization Opset Compatibility Guard Violation
    - Test: test_vuln_23_layernorm_opset_version_guard_violation
    - Source: src/neuron_toolkit/compiler/passes/canonicalization/norm_canonicalizer.py
    - Root Cause: Standard ONNX LayerNormalization was introduced in Opset 17. Emitting standard domain op on Opset 14 caused validation failure.
    - Resolution: Upgraded model opset import to 17 for modern_onnx, and set domain="custom.pytorch" with attached FunctionProto otherwise.
    - Status: PASSED

6.  [RESOLVED] CSE Step 1 Drops Constant Nodes Producing Exposed Graph Outputs
    - Test: test_vuln_24_cse_drops_constant_graph_outputs
    - Source: src/neuron_toolkit/compiler/passes/canonicalization/shape_canonicalizer.py
    - Root Cause: Constant deduplication dropped identical Constant nodes whose output names were exposed in `graph.output`.
    - Resolution: Guarded against removing or rewriting any Constant node whose output is listed in `graph_outputs`.
    - Status: PASSED

7.  [RESOLVED] Cast-Initializer Folding Prunes Initializers Consumed Inside Subgraphs
    - Test: test_vuln_25_cast_folding_drops_control_flow_subgraph_initializers
    - Source: src/neuron_toolkit/compiler/passes/canonicalization/shape_canonicalizer.py
    - Root Cause: `consumed_raw` only checked top-level node inputs, missing initializers referenced inside control-flow subgraphs (`If.then_branch`, `Loop.body`).
    - Resolution: Implemented recursive `collect_consumed` traversing nested `AttributeProto.GRAPH` and `GRAPHS`.
    - Status: PASSED

8.  [RESOLVED] Static Subgraph Folding Is a Hollow Unimplemented No-Op
    - Test: test_vuln_26_static_subgraph_folding_is_unimplemented_noop
    - Source: src/neuron_toolkit/compiler/passes/canonicalization/static_folder.py
    - Root Cause: Identified foldable nodes but never evaluated them or produced initializers, leaving static arithmetic uncollapsed.
    - Resolution: Integrated ONNX ReferenceEvaluator with NumPy fallback to evaluate static sub-DAGs and materialize them as initializers.
    - Status: PASSED

9.  [RESOLVED] GatedAttention Formal Input Count Mismatch on Unbiased Projection

10. [RESOLVED] ScaledDotProductAttention Runtime Registry Ignores 4th Input (attn_mask)

    - Resolution: Added `attn_mask` addition to unnormalized attention scores prior to softmax computation.
    - Status: PASSED

11. [RESOLVED] RotaryEmbedding Runtime Crashes on Partial Head Dimension
    - Test: test_vuln_29_rotary_embedding_crashes_on_partial_head_dim
